Sherrington-Kirkpatrick Model

Note

A Jupyter notebook related to this example is available in our examples folder.

The cost function of the SK model is defined as

\[\begin{align*} C(\sigma) = \frac{1}{\sqrt{N}}\sum_{i<j\leq N} J_{ij} \sigma_i \sigma_j, \end{align*}\]

where the couplings $J_{ij}$ are i.i.d. standard Gaussian variables, i.e. with zero mean $\left\langle J_{ij} \right\rangle = 0$ and unit variance $\left\langle J_{ij}^2 \right\rangle = 1$. The goal is to minimize $C$, i.e. to find the ground state of this spin glass.

We can set this model up as follows, with the factor $1/\sqrt{N}$ included in J:

using QAOA, Random

N = 12
rng = Xoshiro(1)
J = zeros(N, N)
for j in 1:N, i in 1:j-1
    J[i, j] = J[j, i] = randn(rng) / sqrt(N)
end

We have two options to get the corresponding IsingProblem from QAOA.jl. We can pass the coupling matrix J directly:

SK_problem = IsingProblem(zeros(N), J)
IsingProblem{Float64}: 12 spins, sense = :min

or we can use a predefined wrapper function that constructs J in the same way and directly returns an IsingProblem:

SK_problem = sherrington_kirkpatrick(N; seed = 1)
IsingProblem{Float64}: 12 spins, sense = :min

Note that QAOA.jl minimizes the cost function by default, so here we do not need to pass a sense.

For 12 spins, we can still search through all 4096 bitstrings to find the lowest energy:

spins(b) = [2 * ((b >> (i - 1)) & 1) - 1 for i in 1:N]
ground_energy = minimum(objective(SK_problem, spins(b)) for b in 0:2^N-1)
-7.2719180000163295

Annealing

Given SK_problem, we can simulate a quantum annealing with a linear_schedule of p layers. solve then measures the final state 1000 times:

for p in (10, 50)
    result = solve(SK_problem, linear_schedule(p); rng = Xoshiro(1))
    println("p = $p: average energy ", round(result.expectation; digits = 3),
            ", lowest measured energy ", round(result.objective; digits = 3),
            ", measured with probability ", round(result.probability; digits = 3))
end
p = 10: average energy -5.816, lowest measured energy -7.272, measured with probability 0.066
p = 50: average energy -6.842, lowest measured energy -7.272, measured with probability 0.248

Both runs find the ground state. With 50 layers, a quarter of all measurements return it.

Optimized Angles

Alternatively, we can optimize the angles of three layers with optimize_schedule:

tuned, energy = optimize_schedule(SK_problem, 3)

Like the cut of MaxCut, the energy of the SK model does not change when all spins flip, so the QAOA state has the same symmetry. The Workspace thus stores only half of the state, which halves memory and time:

Workspace(SK_problem)
Workspace for IsingProblem{Float64}: 12 spins, sense = :min: 12 qubits, folded to 11 by symmetry
